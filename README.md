# Shopee Profit Dashboard

เว็บ dashboard สำหรับอ่านไฟล์รายได้ Shopee และเก็บ orders/products ใน Cloud Firestore

## การเข้าถึง

เว็บใช้ Google Sign-In และจำกัด Firestore ให้บัญชีเจ้าของที่ยืนยันอีเมลแล้ว

ระบบนำเข้าไฟล์ Excel จะค้นหาชีตและหัวตารางให้อัตโนมัติ จึงรองรับไฟล์ Shopee ที่มีชีต `Summary` อยู่ก่อนชีต `Income` ด้วย ไฟล์ `Income` ใช้ยอดเงินที่โอนแล้วคำนวณกำไร แต่ไม่มีชื่อสินค้าในตัวไฟล์ ดังนั้นให้อัปโหลดไฟล์ `Orders` พร้อมกันเมื่อจำเป็นต้องจับคู่ชื่อสินค้า SKU และต้นทุน ระบบจะรวมข้อมูลด้วยหมายเลขคำสั่งซื้อและแสดงตัวอย่างก่อนบันทึก

หน้าจอ Orders เลือกปี/เดือนและเรียงรายการได้ 6 แบบ โดยค่าเริ่มต้นจะแสดงปี 2026 และเรียงรายการใหม่สุดก่อน ปุ่ม `Export PDF` จะสร้างรายงานจากรายการและตัวกรองที่กำลังเปิดอยู่

หน้า Cost รองรับเพิ่ม แก้ไข ลบ ค้นหา และกรองรายการที่ยังไม่มีชื่อหรือต้นทุนเป็นศูนย์ การเปลี่ยนต้นทุนจะคำนวณออเดอร์ที่มี `lineItems` ของ SKU นั้นใหม่ให้ด้วย

## การนำเข้าปี 2026

เมื่อเลือกไฟล์ ระบบจะยังไม่เขียน Firestore ทันที แต่จะแสดงจำนวนแถว ช่วงวันที่ จำนวนออเดอร์ปี 2026 รายการเก่าที่จะถูกตัดออก และรายการที่ยังไม่มีรายละเอียดสินค้า ให้เลือกได้สองแบบ:

- `เพิ่มต่อท้าย` เก็บ Orders เดิมไว้และข้ามหมายเลขคำสั่งซื้อที่มีอยู่แล้ว
- `ล้างเดิมแล้วใช้ชุดนี้` ต้องดาวน์โหลด JSON Backup ก่อน จากนั้นยืนยันจำนวนรายการที่จะลบ ระบบจะลบเฉพาะ collection `orders` และเก็บ `products` ไว้

ไฟล์ Income ที่ใช้เพียงไฟล์เดียวจะนำเข้ารายการปี 2026 ได้ แต่รายการที่ไม่มีข้อมูลสินค้าเฉพาะจะมีต้นทุนเป็น 0 จนกว่าจะนำเข้าไฟล์ Orders ที่มีรายละเอียดสินค้า

## ตรวจสอบก่อน deploy

```bash
npm test
npx -y firebase-tools@latest deploy --only firestore:rules --project shopee-profit-app
```

GitHub Pages ใช้ `index.html` เป็น static site ส่วน Firebase ใช้ `firebase.json` และ `firestore.rules` เป็น source of truth
